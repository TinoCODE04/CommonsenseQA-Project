# 常识问答实验演示台

目的：在课程演示中体验本组已微调的 RoBERTa-base，并检查真实的开发集实验与案例。用户已确认 Gradio 方案并要求直接在 web 目录创建和执行。

## 范围与界面

- 中文界面、英文问题及 A–E 五个英文选项；不自动翻译。
- 三个标签页：模型体验、案例分析、实验结果。
- 模型体验接受可编辑题目；点击预测后显示实际模型选择、五项 softmax 相对得分、实测耗时。参考答案不进入推理输入。
- 从已有验证集记录载入示例；编辑或更换题目后清空旧预测。
- 案例分析可筛选答对/答错、搜索问题或 ID，显示参考答案与已记录预测，并明确标记为离线评估记录。微调前逐题结果来自事后重建初始模型的补充评估，标明来源。
- 实验页从现有报告计算/读取准确率、题数、训练设置、耗时，展示已有训练曲线；明确是验证集成绩，公开 test 无标签。

## 实现约束

- 使用本地 outputs/full-roberta-base/checkpoint-1827；CPU FP32，4 线程，max_length=128，与训练编码方式一致。
- 模型首次预测时加载，单进程缓存；队列串行预测，torch.inference_mode，不下载、不训练。
- 服务只监听 127.0.0.1，share=False，关闭 Gradio analytics；不暴露模型目录或整个项目目录。
- 原训练脚本、配置、报告、检查点、requirements-lock.txt 保持现有内容。网页依赖和文档放 web，安装时约束已有依赖。
- 对空问题、缺少选项、超长输入、缺失模型/报告给出可操作的中文提示。用户和数据集文本插入 HTML 前转义。
- 得分不解释为正确概率；不生成伪造的模型推理理由，不宣称超过原论文 test 结果。

## 视觉

面向课堂投屏与个人笔记本使用，浅色科研工作台：深蓝文字、蓝色主要操作、青绿色正确状态、红色错误状态。以问题输入和答案结果为主要层级，留足可读间距；双栏桌面布局在窄屏自然堆叠。不依赖远程字体或外部图片。

## 验收

真实检查点单题推理与已保存 logits 对照；全量逐题文件重新计数与报告一致；验证输入和 HTML 转义测试；浏览器检查主流程、筛选搜索、清空旧结果、空输入错误、桌面和手机布局、页面错误日志。
