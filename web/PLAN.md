# CommonsenseQA Web Implementation Plan

Goal: 在 web 目录交付可本地启动、连接真实检查点的 Gradio 课程演示。
Spec: web/DESIGN.md。用户要求直接执行；在当前工作区完成，不提交或改动已有暂存内容。

## 文件

- inference.py：输入检查、编码、CPU 检查点推理，返回选项标签和相对得分。
- experiment.py：读取/核查现有报告与逐题记录，筛选与搜索。
- presentation.py、style.css：安全渲染结果、案例与实验概览。
- app.py：Gradio 组件、事件、命令行本地启动。
- requirements.txt、requirements-lock.txt：新增依赖入口与实际网页环境版本。
- start.ps1、README.md：一键启动及操作说明。
- tests/：输入、得分、真实文件计数、HTML 转义的测试。

## 全局约束

只读现有训练产物；本地离线模型；CPU FP32/4 线程/128 tokens；五选一；不传标签给模型；服务 127.0.0.1、无公开分享；保留原训练依赖锁。
